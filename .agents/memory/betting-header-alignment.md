---
name: Betting header alignment
description: The user's persistent requirement for top navigation action placement.
---

Keep the header's theme, currency, account, notification, and sign-in controls pinned to the right edge at every viewport width. Do not let the action group drift toward the center.

**Why:** The user repeatedly identified centered header controls as a mismatch with the production layout.

**How to apply:** When changing the header, verify guest and authenticated states at phone, tablet, and desktop widths; compare live markup and assets before changing layout rules.
