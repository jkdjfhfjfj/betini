---
name: Admin-managed match sections
description: Product rule for countries and special competition tabs in the match feed.
---

Countries, Zoom Soccer, Jackpots, New, and Turbo use administrator-managed match labels; do not infer section membership from odds or timestamps.

**Why:** the user selected admin-managed labels for the remaining match sections.

**How to apply:** Preserve the admin-set country and section assignments whenever changing match feed filtering or display.

The dashboard's All view must clear section, country, date, market, and odds-only restrictions and include both live and upcoming fixtures; start users in this broad view so filters are opt-in.

**Why:** the user reported that default dashboard filters hid fixtures across many tournaments and asked that All truly show the complete active feed.

**How to apply:** Keep narrower views explicit, and ensure resetting filters also clears any admin-managed section selection.
